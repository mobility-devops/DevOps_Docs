# adr

주요 결정 기록(ADR, Architecture Decision Record). **무엇을 왜 그렇게 정했는지**를 남긴다.
결정 근거의 원본은 노션 「아키텍처 수정안」이다.

- 파일 이름은 번호와 주제로 쓴다. 예: `0001-gateway-api.md`
- 한 번 확정한 ADR은 고치지 않는다. 결정이 바뀌면 새 ADR을 쓰고, 이전 ADR의 상태를 `대체됨(0005)`으로 바꾼다.

## 형식

```markdown
# 0001. 결정 제목

> 담당: 이름 · 기준일: YYYY-MM-DD · 원본: [노션 「문서 이름」](노션 링크)
> 상태: 확정 | 대체됨(번호)

## 배경
## 결정
## 이유
## 영향
```
